# Momentum

A lightweight, client-side **Vanilla** overhaul for Minecraft `1.21.11` that injects tactile weight and minimalist HUD design into everyday gameplay.

Built around frame-rate independent spring-damper physics so every camera turn, landing, and hit feels crisp at 60 FPS or 240+ FPS.

---

## Features 

### Tactile Viewmodel Physics
Features smooth spring-driven item sway, heavy landing recoil on falls over 1 block and mathematically damped viewmodel flinch when taking damage.

### Minimalist Terminal HUD
Features a deep-dark, neon-green terminal HUD with health, armor, and hunger readouts, delayed damage drain indicators, and subtle impact-based HUD shake.

### Native Screen-Space Atmosphere
Features native Minecraft 1.21.11 post-processing with no external dependencies, tactile/cyan color grading, and depth-based atmospheric fog.
